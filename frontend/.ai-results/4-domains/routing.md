# Routing Domain Analysis

## Overview

The routing domain handles navigation within the Roman Redis Manager application using Vue Router 4 with file-based routing powered by unplugin-vue-router.

## Core Technologies

- **Vue Router 4** (v4.5.1)
- **unplugin-vue-router** (v0.15.0) - File-based routing
- **vite-plugin-vue-layouts-next** (v1.0.0) - Layout integration
- **TypeScript** - Fully typed routes

## Router Configuration

### Main Router Setup (src/router/index.ts)

```typescript
import { createRouter, createWebHistory } from "vue-router";
import { setupLayouts } from "virtual:generated-layouts";
import { routes } from "vue-router/auto-routes";

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: setupLayouts(routes),
});

// Workaround for https://github.com/vitejs/vite/issues/11804
router.onError((err, to) => {
  if (err?.message?.includes?.("Failed to fetch dynamically imported module")) {
    if (localStorage.getItem("vuetify:dynamic-reload")) {
      console.error("Dynamic import error, reloading page did not fix it", err);
    } else {
      console.log("Reloading page to fix dynamic import error");
      localStorage.setItem("vuetify:dynamic-reload", "true");
      location.assign(to.fullPath);
    }
  } else {
    console.error(err);
  }
});

router.isReady().then(() => {
  localStorage.removeItem("vuetify:dynamic-reload");
});

export default router;
```

## Key Conventions

### 1. File-Based Routing

Routes are automatically generated from files in `src/pages/`:

**File Structure → Routes:**

- `src/pages/index.vue` → `/`
- `src/pages/about.vue` → `/about`
- `src/pages/users/index.vue` → `/users`
- `src/pages/users/[id].vue` → `/users/:id`

### 2. Current Route Structure

Based on the codebase:

- `src/pages/index.vue` - Home page route (`/`)

### 3. Auto-Generated Routes

Routes are imported from `vue-router/auto-routes`:

```typescript
import { routes } from "vue-router/auto-routes";
```

This is a virtual module generated by unplugin-vue-router based on the `src/pages/` directory structure.

### 4. Layout Integration

Routes are wrapped with layouts using `setupLayouts`:

```typescript
import { setupLayouts } from 'virtual:generated-layouts'
routes: setupLayouts(routes),
```

This integrates the file-based routing with the layout system.

### 5. History Mode

Uses HTML5 History API (createWebHistory):

```typescript
history: createWebHistory(import.meta.env.BASE_URL);
```

This enables clean URLs without hash fragments.

Vue Router composables are auto-imported via unplugin-auto-import:

```typescript
// In vite.config.mts
AutoImport({
  imports: [
    "vue",
    VueRouterAutoImports, // Auto-imports router composables
    {
      pinia: ["defineStore", "storeToRefs"],
    },
  ],
});
```

Available auto-imported composables:

- `useRouter()` - Access router instance
- `useRoute()` - Access current route
- `useLink()` - Router link composable

## Navigation Patterns

### Programmatic Navigation

```typescript
// In component with <script setup>
const router = useRouter();

// Navigate to route
router.push("/");
router.push("/users");
router.push({ name: "user-detail", params: { id: "123" } });

// Navigate with query
router.push({ path: "/search", query: { q: "test" } });

// Go back
router.back();
```

### Declarative Navigation

```vue
<!-- Using router-link (auto-imported component) -->
<router-link to="/">Home</router-link>
<router-link to="/about">About</router-link>

<!-- With Vuetify button -->
<v-btn to="/">Home</v-btn>
<v-btn :to="{ name: 'about' }">About</v-btn>
```

### Accessing Current Route

```typescript
const route = useRoute();

// Access route data
const currentPath = route.path;
const routeName = route.name;
const params = route.params;
const query = route.query;
```

## Adding New Routes

To add a new route:

1. **Create a Vue file in `src/pages/`**

   ```
   src/pages/redis.vue → /redis
   src/pages/settings.vue → /settings
   ```

2. **For nested routes, use folders**

   ```
   src/pages/databases/index.vue → /databases
   src/pages/databases/[id].vue → /databases/:id
   ```

3. **Dynamic segments use brackets**

   ```
   src/pages/keys/[key].vue → /keys/:key
   ```

4. **Route is automatically available**
   - No manual route registration needed
   - Types automatically generated
   - Navigate using file-based path

## Layout System Integration

Routes can specify layouts in route meta:

```vue
<!-- src/pages/index.vue -->
<template>
  <div>Page content</div>
</template>

<route lang="yaml">
meta:
  layout: default
</route>
```

If no layout specified, uses `default.vue` layout automatically.

## Best Practices

1. **Use file-based routing** - Don't manually register routes
2. **Follow naming conventions** - Use lowercase with hyphens for URLs
3. **Leverage type safety** - Use TypeScript route definitions
4. **Use auto-imported composables** - No need to import `useRouter` or `useRoute`
5. **Handle navigation errors** - The router already handles dynamic import errors
6. **Use Vuetify navigation components** - `v-btn` supports `to` prop for routing

## Route Meta and Guards

### Adding Route Meta

```vue
<route lang="yaml">
meta:
  requiresAuth: true
  title: "Dashboard"
</route>
```

### Navigation Guards

Can be added to router/index.ts:

```typescript
router.beforeEach((to, from) => {
  // Check authentication, permissions, etc.
  if (to.meta.requiresAuth && !isAuthenticated()) {
    return "/login";
  }
});
```

# Router Configuration Style Guide

## Overview

Router configuration uses Vue Router 4 with file-based routing powered by unplugin-vue-router and layout integration.

## Router Setup

### Main Configuration (src/router/index.ts)

```typescript
/**
 * router/index.ts
 *
 * Automatic routes for `./src/pages/*.vue`
 */

// Composables
import { createRouter, createWebHistory } from "vue-router";
import { setupLayouts } from "virtual:generated-layouts";
import { routes } from "vue-router/auto-routes";

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: setupLayouts(routes),
});

// Workaround for https://github.com/vitejs/vite/issues/11804
router.onError((err, to) => {
  if (err?.message?.includes?.("Failed to fetch dynamically imported module")) {
    if (localStorage.getItem("vuetify:dynamic-reload")) {
      console.error("Dynamic import error, reloading page did not fix it", err);
    } else {
      console.log("Reloading page to fix dynamic import error");
      localStorage.setItem("vuetify:dynamic-reload", "true");
      location.assign(to.fullPath);
    }
  } else {
    console.error(err);
  }
});

router.isReady().then(() => {
  localStorage.removeItem("vuetify:dynamic-reload");
});

export default router;
```

## Unique Conventions

### 1. Virtual Module Imports

Routes are imported from virtual modules:

```typescript
// ✅ From virtual module generated by unplugin-vue-router
import { routes } from "vue-router/auto-routes";
import { setupLayouts } from "virtual:generated-layouts";

// ❌ Not manually defined
// const routes = [
//   { path: '/', component: Home }
// ]
```

These modules are generated at build time based on `src/pages/` structure.

### 2. Layout Integration

Routes are wrapped with layouts before router creation:

```typescript
const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: setupLayouts(routes), // ← Wraps routes with layouts
});
```

This is unique - layouts are applied at router configuration level.

### 3. Dynamic Import Error Handling

Special error handling for Vite build issues:

```typescript
router.onError((err, to) => {
  if (err?.message?.includes?.("Failed to fetch dynamically imported module")) {
    if (localStorage.getItem("vuetify:dynamic-reload")) {
      console.error("Dynamic import error, reloading page did not fix it", err);
    } else {
      console.log("Reloading page to fix dynamic import error");
      localStorage.setItem("vuetify:dynamic-reload", "true");
      location.assign(to.fullPath);
    }
  } else {
    console.error(err);
  }
});
```

**Purpose**: Handles code-split chunk loading failures after deployments by reloading the page once.

### 4. Router Ready Cleanup

Cleanup after router initialization:

```typescript
router.isReady().then(() => {
  localStorage.removeItem("vuetify:dynamic-reload");
});
```

Removes the reload flag after successful initialization.

### 5. History Mode

Uses HTML5 History API:

```typescript
history: createWebHistory(import.meta.env.BASE_URL);
```

**Note**: `import.meta.env.BASE_URL` comes from Vite environment.

### 6. No Manual Route Definitions

Zero manual route definitions - all routes come from file system:

```typescript
// ✅ This project - routes auto-generated
import { routes } from "vue-router/auto-routes";

// ❌ Traditional approach - not used
// const routes = [
//   { path: '/', name: 'home', component: Home },
//   { path: '/about', name: 'about', component: About }
// ]
```

## Plugin Registration

### Router in Plugin System

```typescript
// src/plugins/index.ts
import router from "../router";

export function registerPlugins(app: App) {
  app
    .use(vuetify)
    .use(router) // Registered before pinia
    .use(pinia);
}
```

**Order**: vuetify → router → pinia

## Type Safety

### Auto-Generated Types

Router types are auto-generated:

```typescript
// src/typed-router.d.ts (auto-generated)
// Contains TypeScript definitions for all routes
```

This file should never be edited manually.

## Customization Patterns

### Adding Navigation Guards

```typescript
// Add before router.onError()
router.beforeEach((to, from) => {
  // Check authentication
  if (to.meta.requiresAuth && !isAuthenticated()) {
    return { name: "login" };
  }

  // Update document title
  if (to.meta.title) {
    document.title = to.meta.title as string;
  }
});
```

### Adding After Hooks

```typescript
router.afterEach((to, from) => {
  // Analytics tracking
  trackPageView(to.path);

  // Scroll to top
  window.scrollTo(0, 0);
});
```

### Progress Indicator

```typescript
import { useAppStore } from "@/stores/app";

router.beforeEach((to, from) => {
  const appStore = useAppStore();
  appStore.startLoading();
});

router.afterEach(() => {
  const appStore = useAppStore();
  appStore.stopLoading();
});
```

## What Makes Router Config Unique

1. **File-Based Routes**: Routes generated from files, not manually defined
2. **Virtual Modules**: Imports from Vite virtual modules
3. **Layout Integration**: Routes wrapped with layouts at config level
4. **Dynamic Import Error Recovery**: Specific error handling for chunk loading
5. **Minimal Configuration**: Very little manual configuration needed
6. **Type-Safe**: Fully typed routes via auto-generation

## Router Configuration Checklist

- [ ] Keep `src/router/index.ts` minimal
- [ ] Don't manually define routes
- [ ] Don't edit `src/typed-router.d.ts`
- [ ] Keep dynamic import error handler
- [ ] Add navigation guards before `router.onError()`
- [ ] Use `router.beforeEach/afterEach` for global logic
- [ ] Import from virtual modules (`vue-router/auto-routes`)
- [ ] Export single router instance

## Common Customizations

### Authentication Guard

```typescript
import { useAuthStore } from "@/stores/auth";

router.beforeEach(async (to, from) => {
  const authStore = useAuthStore();

  // Public routes
  const publicPages = ["/login", "/signup"];
  const authRequired = !publicPages.includes(to.path);

  if (authRequired && !authStore.isAuthenticated) {
    return { path: "/login", query: { redirect: to.fullPath } };
  }
});
```

### Role-Based Access

```typescript
router.beforeEach((to, from) => {
  const authStore = useAuthStore();
  const requiredRoles = to.meta.roles as string[] | undefined;

  if (requiredRoles && !authStore.hasAnyRole(requiredRoles)) {
    return { path: "/unauthorized" };
  }
});
```

### Loading Bar

```typescript
let isLoading = false;

router.beforeEach((to, from) => {
  if (!isLoading) {
    isLoading = true;
    // Show loading bar
  }
});

router.afterEach(() => {
  isLoading = false;
  // Hide loading bar
});
```

### Scroll Behavior

```typescript
const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes: setupLayouts(routes),
  scrollBehavior(to, from, savedPosition) {
    if (savedPosition) {
      return savedPosition;
    } else if (to.hash) {
      return { el: to.hash, behavior: "smooth" };
    } else {
      return { top: 0 };
    }
  },
});
```

### Page Transitions

```typescript
router.beforeEach((to, from) => {
  // Set transition name based on navigation direction
  const toDepth = to.path.split("/").length;
  const fromDepth = from.path.split("/").length;
  to.meta.transitionName = toDepth < fromDepth ? "slide-right" : "slide-left";
});
```

## Error Handling Best Practices

### Preserve Original Error Handler

```typescript
// Keep the dynamic import handler
router.onError((err, to) => {
  if (err?.message?.includes?.("Failed to fetch dynamically imported module")) {
    // ... existing handler
  } else if (err?.message?.includes?.("NotFound")) {
    router.push("/404");
  } else {
    console.error(err);
    // Show error toast
  }
});
```

### Don't Remove Reload Logic

The dynamic import error handler should be preserved as-is:

```typescript
// ✅ Keep this as-is
router.onError((err, to) => {
  if (err?.message?.includes?.("Failed to fetch dynamically imported module")) {
    if (localStorage.getItem("vuetify:dynamic-reload")) {
      console.error("Dynamic import error, reloading page did not fix it", err);
    } else {
      console.log("Reloading page to fix dynamic import error");
      localStorage.setItem("vuetify:dynamic-reload", "true");
      location.assign(to.fullPath);
    }
  } else {
    console.error(err);
  }
});
```

This handles a known Vite issue where code-split chunks fail to load after deployments.
